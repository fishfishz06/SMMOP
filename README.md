# 🏗️ 結構與材料力學線上計算器 (SMMOP)

這是基於 Web 技術開發的結構學與材料力學輔助計算工具庫。

## 🌟 功能特點
- **莫爾圓 (Mohr's Circle) 分析儀**：支援拉逆為正座標系、極點 (O.P.) 幾何定位與三方塊實體微小應力元素繪製。
- **線上目錄頁**：採用深粉紅/玫紅風格呈現響應式工具選單。

## 🌐 線上展示
網站已透過 GitHub Pages 發布：[點此造訪網站](https://fishfishz06.github.io/SMMOP/)

## 🛠️ 使用技術
- HTML5 / CSS3 / JavaScript
- Tailwind CSS
- HTML5 Canvas (動態應力繪圖)
